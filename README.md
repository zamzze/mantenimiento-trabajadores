# Mantenimiento de Trabajadores - ASP.NET Core MVC

Módulo web para el mantenimiento de trabajadores desarrollado en ASP.NET Core MVC.

## Tecnologías
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap
- Stored Procedures

## Funcionalidades
- CRUD de trabajadores
- Subida de foto
- Filtro por sexo
- UI responsive
- Uso de procedimientos almacenados

## Base de Datos
La base de datos fue desarrollada en SQL Server.
Por limitaciones de los proveedores cloud gratuitos, la BD se ejecuta en entorno local.
El proyecto es totalmente portable a SQL Server en la nube.
