# Mantenimiento de Trabajadores - ASP.NET Core MVC

Módulo web para el mantenimiento de trabajadores desarrollado en ASP.NET Core MVC.

## Tecnologías
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap
- Stored Procedures

## Funcionalidades
- CRUD de trabajadores
- Subida de foto
- Filtro por sexo
- UI responsive
- Uso de procedimientos almacenados

## Base de Datos
La base de datos fue desarrollada en SQL Server.
El proyecto es totalmente portable a bases de datos en la nube.
